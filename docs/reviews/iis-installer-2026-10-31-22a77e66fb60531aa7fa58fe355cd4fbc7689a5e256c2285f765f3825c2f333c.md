### 1. `install-iis.ps1` Functionality & Platform Compatibility

- **PowerShell 5.1 and 7 Compatibility**:
  - The script relies exclusively on native cmdlets and .NET APIs supported in Windows PowerShell 5.1 and PowerShell 7: `#Requires -RunAsAdministrator` ([line 1](../../install-iis.ps1#L1)), `[CmdletBinding(SupportsShouldProcess = $true)]` ([line 42](../../install-iis.ps1#L42)), `[ordered]@{}` ([line 92](../../install-iis.ps1#L92)), `Get-FileHash` ([line 218](../../install-iis.ps1#L218)), and `[Environment]::Is64BitProcess` ([line 198](../../install-iis.ps1#L198)).
  - Type definition caching guard (`if (-not ('BrotliIis.Cpu' -as [type]))` on [line 209](../../install-iis.ps1#L209)) ensures `Add-Type` does not fail on repeated executions within the same session.
  - Strict compliance with `Set-StrictMode -Version 2.0` ([line 65](../../install-iis.ps1#L65)); all variables and hashtable lookups are strictly initialized and guarded against `$null` member dereference.

- **Native Argument Quoting & `appcmd.exe` Command Syntax**:
  - All calls to `appcmd.exe` pass arguments as array elements through PowerShell splatting (`& $AppCmd @Arguments 2>&1` on [line 77](../../install-iis.ps1#L77)).
  - Arguments with embedded spaces (e.g. `C:\Program Files\IIS\IIS Compression\...`) are quoted cleanly by PowerShell when passing to the native Windows command line. Collection syntax values are enclosed in single quotes internally (`$_='$($Attrs[$_])'` on [line 129](../../install-iis.ps1#L129)), which are safely passed through to `appcmd.exe`.
  - Single-quote rejection on scheme attribute values ([line 119](../../install-iis.ps1#L119)) prevents command injection or parsing syntax errors.
  - Exit codes from `appcmd.exe` are checked immediately ([lines 78–80](../../install-iis.ps1#L78-L80)); any non-zero exit throws an exception containing the exact command line and error output.

- **`ShouldProcess` & `-WhatIf` / `-Confirm` Coverage**:
  - All mutating actions—`appcmd add backup`, directory creation, undo note emission, DLL file copying, scheme addition/repoint, and proxy configuration—are contained in a single `$PSCmdlet.ShouldProcess($Section, ...)` block ([line 273](../../install-iis.ps1#L273)).
  - The service restart is separately guarded by `$PSCmdlet.ShouldProcess('W3SVC', ...)` ([line 172](../../install-iis.ps1#L172)).
  - Under `-WhatIf`, `$WhatIfPreference` ensures no mutating actions occur while describing the changes and demonstrating that W3SVC restart would be requested.
  - Declining confirmation on the change set halts activation cleanly ([lines 308–311](../../install-iis.ps1#L308-L311)), preventing partial execution or erroneous verification.

- **Idempotence on Re-run**:
  - Evaluates `$copyNeeded`, `$schemeNeeded`, and `$proxyNeeded` upfront ([lines 235–256](../../install-iis.ps1#L235-L256)).
  - If the target DLL exists with the identical SHA-256 hash, `br` is already the first scheme with matching attributes, and proxy attributes match, the script outputs `Already installed with these settings; nothing to change.` ([line 260](../../install-iis.ps1#L260)) and makes no configuration modifications.

- **Undo Note & Rollback Fidelity**:
  - An `appcmd` backup named `brotli-iis-<yyyyMMdd-HHmmss>` is captured prior to making any system changes ([line 274](../../install-iis.ps1#L274)).
  - The undo text file (`brotli-iis-undo-<timestamp>.txt`) is created prior to modifying files or configuration ([line 277](../../install-iis.ps1#L277)).
  - The undo script uses full paths to `appcmd.exe` ([line 140](../../install-iis.ps1#L140)) to ensure runnable execution on systems where `inetsrv` is not in `$env:PATH`.
  - Values are escaped using single-quote doubling via `Q()` ([line 139](../../install-iis.ps1#L139)).
  - If `br` previously existed, all original scheme attributes are restored, pointing back to the preserved previous version DLL. If `br` was not originally first, the undo file explicitly alerts the operator that setting attributes leaves `br` first and supplies the exact `appcmd restore backup <backup>` command for a complete schema and ordering revert ([lines 146–152, 163–166](../../install-iis.ps1#L146-L152)).

- **Partial-Failure Recovery**:
  - Step sequencing is strictly ordered: Backup -> Directory -> Undo Note -> File Copy -> Scheme Config -> Proxy Config -> Post-Validation.
  - If an installation fails between scheme removal and re-addition at `@start`, post-check validation catches it ([lines 292–296](../../install-iis.ps1#L292-L296)), directing the operator to the backup restoration command documented in the pre-written undo file.

- **`-VerifyUrl` Check**:
  - Preflight strictly enforces that `-VerifyUrl` requires `-RestartWww` ([line 193](../../install-iis.ps1#L193)), preventing false certification against worker processes that have not loaded the updated DLL.
  - Verification queries the URL via `curl.exe` with `Accept-Encoding: br` ([line 182](../../install-iis.ps1#L182)), inspects the final `Content-Encoding` header, and throws if the response is uncompressed or encoded under another scheme.

### 2. IIS Configuration & System Safety

- **Other Schemes & Scheme Prioritization**:
  - If `br` is already the first scheme, attributes are updated in-place ([lines 121–125](../../install-iis.ps1#L121-L125)) in a single apphost commit.
  - If `br` is present but not first, only `[name='br']` is removed and re-added at `@start` ([lines 126–130](../../install-iis.ps1#L126-L130)). Other schemes (`gzip`, `deflate`) are never removed, edited, or reordered relative to each other.
- **MIME Tables & Site Settings**:
  - The script does not alter `<staticTypes>`, `<dynamicTypes>`, or site-level configuration; all changes are constrained to the root `system.webServer/httpCompression` section ([line 67](../../install-iis.ps1#L67)).
- **DLL in Use Safety**:
  - Deploys version-stamped filenames (`brotli-<version>.dll` on [line 226](../../install-iis.ps1#L226)), avoiding file lock collisions with `w3wp.exe`.
  - Refuses to overwrite an existing DLL if its hash does not match ([lines 238–240](../../install-iis.ps1#L238-L240)).
