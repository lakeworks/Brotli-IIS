### [O2] Proxy-only activation prints an unusable `appcmd` command

`appcmd.exe` is not on PATH by default ([Microsoft AppCmd docs](https://learn.microsoft.com/en-us/iis/get-started/getting-started-with-iis/getting-started-with-appcmdexe#how-to-use-appcmdexe)). The undo note correctly uses the full path (`:140`); this recycle hint does not. On the documented fresh-server setup the command fails. Emit both sides with the resolved `$AppCmd` path (or another PATH-free form).
